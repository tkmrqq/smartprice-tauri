# SmartPrice-BY

Десктопное приложение для розничной торговли в Беларуси: считает розничные цены с учётом
предельных наценок (Постановление СМ РБ № 713), разбирает накладные и прайсы поставщиков,
находит самые выгодные предложения и печатает ценники со штрихкодом.

Построено на **Tauri 2 + Vue 3** (портирование с PyQt6-версии). Вся бизнес-логика — на JavaScript в
`src/lib/` и покрыта юнит-тестами; Rust-часть — тонкая оболочка, которая даёт доступ к SQLite,
файлам, диалогам и сети через официальные плагины Tauri.

![Расчёт цен](docs/screenshots/calculator.png)

## Возможности

### Расчёт цен
Розница считается по цепочке  
`закупка × (1 + наценка поставщика) × (1 + торговая наценка) × (1 + НДС)`.

- Если товар попадает в регулируемую категорию (по ключевым словам в названии), торговая наценка
  автоматически ограничивается предельной; для импортных товаров действует отдельный лимит.
  Статус виден в каждой строке: не регулируется / регулируется / наценка ограничена.
- Список категорий, ключевые слова и лимиты правятся в отдельном окне
  (*Настройки → Редактор категорий*), без пересборки приложения.
- Рост или падение закупки относительно прошлого расчёта показывается значком `▲ 4,6%` / `▼ 2,0%`.
- Ширину колонок можно менять перетаскиванием границы в заголовке (запоминается).
- Текущая таблица, даже нерассчитанная, **сохраняется автоматически** и восстанавливается при запуске.

### Импорт товаров
- **Накладная ЭДИН (XML)** — товары, цены, НДС, страна, штрихкод, вес/объём из названия.
- **Фото накладной** — распознавание через Google Cloud Vision (нужен API-ключ, см. настройки).

![Импорт накладной](docs/screenshots/import.png)

### Справочник товаров
Раздел **Товары**. После расчёта товара со штрихкодом программа запоминает его наценки, страну,
вес, единицу и сорт. При следующем импорте они подставляются сами — вручную остаются только новые
товары. Название, цена закупки, НДС и страна всегда берутся из накладной.

Справочник заполняется автоматически, есть поиск и правка прямо в таблице. При первом запуске новой
версии он один раз наполняется из уже накопленной истории (у записей со штрихкодом).

![Справочник товаров](docs/screenshots/catalog.png)

### Сравнение прайсов поставщиков
Раздел **Сравнение прайсов**: перетащите прайсы (`.xlsx` / `.xls`), колонки определятся автоматически
(их можно поправить вручную), а программа сопоставит одинаковые товары — по штрихкоду, а без него по
похожести названия — и покажет, у кого цена ниже и на сколько. Лучшее предложение отправляется в расчёт
одной кнопкой.

![Сравнение прайсов](docs/screenshots/price-compare.png)

### Ценники
Кнопка **Сформировать ценники** сохраняет `labels.html` (60×42 мм, сетка на A4) — открывается в
браузере и печатается обычным образом.

- Название и УНП организации задаются в *Настройках → Ценники*.
- Штрихкод (EAN-13, EAN-8, UPC-A) печатается по галочке в настройках; он слева внизу, рядом — страна
  и дата. Печатаются только корректные коды: с неверной контрольной цифрой полос не будет, только цифры.
- Название товара печатается **целиком**: если оно длинное, уменьшается шрифт.
- Галочка **«Ценники только по изменившимся»** отбирает товары, у которых розничная цена отличается от
  той, что печаталась в прошлый раз (или товар печатается впервые).

![Ценник](docs/screenshots/label.png)

### История
Каждый расчёт сохраняется. Записи сгруппированы по дням, можно выбрать несколько (Shift — диапазон,
чекбокс в строке дня выбирает весь день) и вернуть их в таблицу расчёта вместе с наценками и НДС.

![История](docs/screenshots/history.png)

### Резервная копия
*Настройки → Резервная копия данных.* Один файл `smartprice-backup-ГГГГ-ММ-ДД.json` содержит историю
расчётов, справочник товаров и настройки (реквизиты ценников, свои категории регулирования). Ключ
Google Vision в копию попадает только по отдельной галочке — в файле он лежит открытым текстом.

Восстановление **ничего не удаляет**, а сливает копию с текущими данными: одинаковые записи истории не
дублируются, а товар справочника заменяется записью из копии, только если она не старше текущей.
Поэтому восстановиться можно и на пустую установку, и поверх работающей, и повторно.

Раз в неделю приложение напоминает о копии баннером под шапкой (в первую неделю после установки — нет).
Копию стоит хранить вне компьютера: на флешке или в облаке.

## Установка и запуск (Windows)

Понадобятся:

1. [Node.js](https://nodejs.org) 20 LTS
2. [Rust](https://rustup.rs) (через `rustup`)
3. **Microsoft C++ Build Tools** — компонент «Разработка классических приложений на C++»
   (без него `cargo` не найдёт линковщик `link.exe`)
4. WebView2 Runtime — на Windows 10/11 обычно уже установлен

Путь к проекту лучше держать без кириллицы и пробелов.

```powershell
npm install
npm run tauri dev      # запуск с горячей перезагрузкой (первая сборка Rust — 5–15 минут)
npm run tauri build    # установщики в src-tauri/target/release/bundle/
npm test               # юнит-тесты бизнес-логики
```

Для Linux/macOS список системных зависимостей — в [документации Tauri](https://v2.tauri.app/start/prerequisites/).

## Релизы

Сборка выпускается GitHub Actions (`.github/workflows/release.yml`) при пуше тега `v*`.

```powershell
git add -A
git commit -m "feat: ..."
npm version minor             # поднимает версию в package.json и создаёт тег vX.Y.Z
git push --follow-tags
```

Версия установщика и имя релиза берутся из `src-tauri/tauri.conf.json`, поэтому там должно быть
`"version": "../package.json"` — иначе тег и собранная версия разойдутся. Для подписи обновлений
в репозитории заданы секреты `TAURI_SIGNING_PRIVATE_KEY` и `TAURI_SIGNING_PRIVATE_KEY_PASSWORD`.

## Где хранятся данные

| Что | Где |
|---|---|
| История расчётов и справочник товаров (их защищает [резервная копия](#резервная-копия)) | SQLite `smartprice.db` в папке данных приложения (`%APPDATA%\by.smartprice.app`) |
| Ключ Vision API, реквизиты ценников, свои категории регулирования | `settings.json` там же |
| Черновик таблицы, ширина колонок, галочка «только изменившиеся» | `localStorage` окна приложения |

`localStorage` у `tauri dev` и у собранного приложения **раздельный**: то, что набрано в режиме
разработки, в установленной версии не появится.

## Известные ограничения

- Шрифты интерфейса подключаются с Google Fonts: без интернета приложение работает, но с системными
  шрифтами. Для полностью офлайн-вида `.woff2` можно положить в проект.
- Распознавание фото накладных требует интернета и ключа Google Vision; расчёт, импорт ЭДИН, прайсы и
  ценники работают офлайн.
- В сравнении прайсов цена берётся из одной колонки (без НДС **или** с НДС) — если у поставщиков разная
  база, их нужно свести вручную.
- Ценник считается напечатанным в момент сохранения `labels.html`.
