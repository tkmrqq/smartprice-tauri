# SmartPrice-РБ — Tauri + Vue

Порт desktop-приложения расчёта розничных цен (Пост. СМ РБ №713) с PyQt6 на
Tauri 2 + Vue 3. Вся бизнес-логика написана на JS и находится в `src/lib/`;
Rust-часть (`src-tauri/`) — тонкая нативная оболочка без собственной бизнес-логики,
всё общение с системой идёт через официальные плагины Tauri.

## Важная оговорка по среде сборки

Этот проект собирался **без доступа к Rust-тулчейну** (в песочнице, где он
писался, не было `cargo`/`rustc`, а установка через rustup была недоступна
из-за сетевых ограничений). Поэтому:

- **JS/Vue-часть полностью проверена**: 20 юнит-тестов (`npm test`) на все
  портированные модули бизнес-логики, плюс `npm run build` — Vite собирает
  весь фронтенд без единой ошибки.
- **Rust/Tauri-часть НЕ скомпилирована и не запускалась.** `Cargo.toml`,
  `main.rs`, `tauri.conf.json` и `capabilities/default.json` написаны по
  актуальной на момент разработки документации Tauri v2, но:
  - названия permission-идентификаторов в `capabilities/default.json`
    могли измениться между минорными версиями Tauri v2 — если при первом
    запуске `tauri dev` ругнётся на неизвестное разрешение, откройте
    сообщение об ошибке (оно обычно прямо называет нужный идентификатор)
    и поправьте файл;
  - версии плагинов в `Cargo.toml` (`tauri-plugin-sql`, `-fs`, `-dialog`,
    `-http`, `-store`) зафиксированы как `"2"` — Cargo подберёт последнюю
    подходящую 2.x на момент вашей сборки, но стоит свериться с
    `@tauri-apps/plugin-*` версиями в `package.json`, они должны совпадать
    по мажорной версии протокола.

Первый `cargo build`/`npm run tauri dev` на вашей машине, скорее всего,
потребует одного-двух мелких исправлений в конфиге — но вся логика внутри
уже проверена, и структура полностью соответствует официальному шаблону
Tauri + Vue.

```bash
npm install

```

## Сборка и запуск

Понадобятся (на вашей машине, не в этой песочнице):
- Node.js 18+
- Rust (через [rustup](https://rustup.rs))
- системные зависимости Tauri для вашей ОС — см.
  https://v2.tauri.app/start/prerequisites/ (на Windows — только WebView2,
  на Linux — webkit2gtk и ряд dev-пакетов, на macOS — Xcode CLT)

```bash
npm install
npm run tauri dev      # режим разработки с горячей перезагрузкой
npm run tauri build    # финальная сборка (.exe/.msi, .AppImage/.deb, .dmg)
```

## Что нужно доделать/проверить руками

1. **Иконки.** Сгенерированы из старого `assets/icon.ico` в PNG/ICO нужных
   размеров, но `.icns` для macOS не создавался (недоступен инструмент вне
   macOS). Проще всего один раз перегенерировать полный набор командой:
   ```bash
   npx tauri icon src-tauri/icons/icon.png
   ```
   Она создаст корректные `icon.icns`, `icon.ico` и все PNG сразу и обновит
   пути — после этого можно ничего не трогать в `tauri.conf.json`.

2. **Права доступа к файлам (`fs:scope`).** Сейчас разрешены каталоги
   `$APPDATA`, `$HOME`, `$DOWNLOAD`, `$DOCUMENT`, `$PICTURE`, `$DESKTOP` —
   этого достаточно для типичного выбора файлов через системный диалог, но
   если у пользователей накладные лежат на сетевом диске или в другом
   нестандартном месте, добавьте путь в `src-tauri/capabilities/default.json`.

3. **Ключ Google Vision.** Хранится через `@tauri-apps/plugin-store` в
   `settings.json` в app data dir — не зашифрован. Если это важно, можно
   переключить на `keyring`/`stronghold`-плагин Tauri.

4. **Шрифты.** `src/style.css` подключает Newsreader/Inter/IBM Plex Mono
   через Google Fonts CDN — при отсутствии интернета в момент первого
   запуска шрифты не подгрузятся, и браузер использует системные
   аналоги (визуально почти незаметно, но для полностью офлайн-надёжной
   сборки лучше самостоятельно скачать `.woff2` и подключить через
   локальный `@font-face`).

5. **Печать ценников.** Сейчас "Сформировать ценники" сохраняет `.html`
   файл на диск (аналог `price_labels.py`, который тоже генерировал HTML).
   Открывается в любом браузере, оттуда — печать (Ctrl+P). Если нужна
   прямая печать без окна браузера — можно добавить
   `@tauri-apps/plugin-shell` для открытия файла в системном приложении
   по умолчанию сразу после сохранения.


## Категории регулирования в отдельном окне

Настройки → «Открыть редактор категорий в отдельном окне» открывает
**настоящее второе нативное окно** ОС (не модалку), через
`@tauri-apps/api/webviewWindow`. Можно держать его открытым на втором
мониторе, редактировать ключевые слова/предельные наценки по каждой
категории Пост. №713 карточками (а не руками в JSON), сохранить —
изменения тут же долетают в главное окно через `@tauri-apps/api/event`.
